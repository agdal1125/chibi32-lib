# Licensing (not decided)

No license has been chosen yet. Until the owner picks one and adds a `LICENSE` file, the code and art in this repository are not licensed for reuse or redistribution.

## What will need a license

| Part | Paths |
|---|---|
| Code | `tools/`, `tests/`, `index.html` |
| Art | `assets/`, `styles/`, `dist/`, `preview/` |

## Options under consideration

- Code: MIT. The only dependency is Pillow, and MIT puts the least burden on users.
- Art: CC0 1.0 (no conditions) or CC BY 4.0 (credit required). CC0 suits a free game-asset library best; CC BY 4.0 fits if attribution matters.

## Open questions before release

- **AI use.** The pixels were written by a language model (Claude). The owner still has to confirm that the tool's terms allow distribution under the chosen license. Every `credits.json` records `"terms_checked": false` until then. Whether AI-assisted output is protected by copyright differs by country. This file is not legal advice.
- **References.** No external images are stored in this repository. The style direction came from reference images of unknown source, used only as a general target; no pixels, shapes or palettes were copied.
