# chibi32 스타일 규칙

[assets/hero/hero.sprite](../../assets/hero/hero.sprite)의 `base` 프레임을 먼저 다듬은 뒤, 거기서 뽑아낸 규칙입니다. 이 스타일로 만드는 새 프레임과 새 에셋은 이 규칙을 따릅니다.
각 규칙 끝에 `[자동]`이 붙은 것은 `tools/check.py`가 검사하고, `[눈]`이 붙은 것은 사람이 렌더 결과를 보고 판단합니다.

## 1. 캔버스와 기준점

- 프레임 크기는 32×32입니다. `[자동]`
- 배경은 완전 투명입니다. 알파는 0 또는 255만 씁니다. `[자동]`
- 프레임 가장자리 1px은 항상 비워 둡니다. 외곽선이 잘리지 않게 하기 위해서입니다. `[자동]`
- 기준점(anchor)은 (16, 29)이며 발바닥 픽셀 줄입니다. 외곽선 맨 아랫줄은 30행입니다. 모든 프레임에서 이 줄이 같아야 합니다. `[자동]`

## 2. 비율과 실루엣

- 머리 16×15, 몸통 10×6, 다리 4행(지지 프레임은 5행)입니다. 외곽선을 빼면 캐릭터 키는 24px(6~29행)이고, 머리가 그중 15px(약 60%)입니다. 머리 맨 아랫줄은 몸통 맨 윗줄과 겹칩니다. `[눈]`
- 오른쪽을 바라보는 3/4 시점입니다. 얼굴은 머리의 오른쪽 2/3에, 뒷머리는 왼쪽 1/3에 둡니다. `[눈]`
- 큰 덩어리 순서는 머리 > 방패 > 몸통 > 다리입니다. 실루엣만 보고도 머리, 검, 방패가 구분되어야 합니다. `[눈]`
- 검은 몸 뒤쪽(왼쪽)에 수직으로 세우고, 칼날이 머리와 겹치지 않게 합니다. 방패는 앞쪽(오른쪽)에서 몸통과 다리를 일부 가립니다. `[눈]`
- 무기는 이 크기에서 수직선과 수평선으로 그립니다. 대각선은 1:1 또는 2:1 기울기만 씁니다. `[눈]`

## 3. 외곽선

- 외곽선은 팔레트의 `K`(#1a1420) 한 색, 1px입니다.
- 외곽선은 손으로 그리지 않고 빌드가 만듭니다. 각 부품(part)을 그리기 직전에 그 부품의 상하좌우 4방향 이웃에 `K`를 칠합니다. 그래서 겹치는 부품 사이에도 구분선이 생깁니다(예: 턱과 어깨, 방패와 몸통). `[자동, 빌드 규칙]`
- 부품 안쪽의 구분선만 grid에 직접 `K`로 그립니다. 현재는 눈만 해당합니다.
- 안티에일리어싱과 반투명 픽셀은 쓰지 않습니다. `[자동]`

## 4. 광원과 명암

- 빛은 왼쪽 위에서 옵니다. 재질마다 밝은 톤은 위·왼쪽 가장자리에, 어두운 톤은 오른쪽·아래에 둡니다. `[눈]`
- 재질별 톤 수는 2~3개입니다. 그림자는 단순히 어둡게 하지 않고 색상을 옮깁니다(머리카락 그림자는 푸른 회색, 피부 그림자는 붉은 쪽).

| 재질 | 밝음 | 중간 | 그림자 |
|---|---|---|---|
| 머리카락 | `W` f6f7fb | `w` c9cddc | `h` 8a8fa8 |
| 피부 | `S` ffdcc0 | | `s` e8a88c (볼 `p` f08c8c) |
| 옷 | `L` 6fa0f2 | `B` 3d6fd6 | `b` 284a9e |
| 가죽 | `N` 9a6038 | | `n` 603822 |
| 금속 | `M` eef3f8 | `m` a9b5c6 | `d` 66718a |
| 금 | `G` f4c24e | | `g` b47f2c |
| 나무 | `O` c27a42 | | `o` 80492a |

- 먼 쪽 팔다리는 그림자 톤으로 칠합니다. 걷기에서 먼 다리는 `b`/`n`, 가까운 다리는 `B`/`N`입니다. `[눈]`
- 팔레트 밖의 색은 쓰지 않습니다. 새 색이 필요하면 [palette.txt](palette.txt)를 고치는데, 그러면 스타일 전체가 바뀌는 것이므로 기존 에셋을 다시 확인해야 합니다. `[자동]`

## 5. 픽셀 배치

- 혼자 떨어진 1px은 의도한 곳에만 둡니다. 눈(1×2, `K`), 볼, 칼끝, 폼멜이 그런 곳입니다. `[눈]`
- 눈은 검은색 1×2 두 개이고, 사이는 3px입니다. 하이라이트는 넣지 않습니다. `[눈]`
- 뾰족머리는 위로 2개, 뒤로 1개 솟은 삐침과 이마로 내려오는 앞머리 삐침으로 그립니다. `[눈]`

## 6. 애니메이션 규칙 (기준 프레임에서 나머지 프레임 만들기)

- 머리, 몸통, 방패, 검 부품은 모든 프레임에서 픽셀이 같습니다. 바뀌는 것은 위치(오프셋)뿐입니다. `[빌드 규칙: 같은 part를 재사용]`
- 걷기는 4프레임 루프입니다. 접지(가까운 다리 앞) → 통과(가까운 다리 지지) → 접지(먼 다리 앞) → 통과(먼 다리 지지) 순서입니다.
- 통과 프레임에서는 상체 전체(머리, 몸통, 방패, 검)를 1px 올리고, 다리는 5행짜리 부품으로 바꿔 몸통과 붙어 있게 합니다. `[눈]`
- 검을 든 팔은 가까운 다리와 반대로 ±1px 흔듭니다. 가까운 다리가 앞이면 -1, 먼 다리가 앞이면 +1입니다. `[눈]`
- 프레임 길이는 기본 150ms입니다. `[자동: 0보다 큰 정수]`

## 자동 검사가 하지 않는 것

이 문서의 `[눈]` 항목, 즉 비율이 보기 좋은지, 명암이 자연스러운지, 걷기가 자연스럽게 보이는지는 자동으로 검증하지 않습니다.
